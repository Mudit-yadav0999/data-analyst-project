# Sales Performance Dashboard | Retail & E-commerce

End-to-end analytics project: **Python (Pandas, NumPy)** for cleaning and EDA -> **Oracle SQL** for storage and analysis -> **Power BI** for an interactive dashboard.

## Project goals
- Clean a messy retail sales dataset and document every cleaning rule
- Store it in a normalised Oracle schema and answer business questions with JOINs, GROUP BY/HAVING, subqueries, CTEs and window functions
- Build an interactive Power BI dashboard whose numbers **reconcile with the SQL results**
- Turn the analysis into business recommendations

## Dataset
`data/raw/Superstore_raw.csv` is a **synthetic, seeded Superstore-style dataset** (10,054 rows) generated by `scripts/generate_dataset.py`. It intentionally contains duplicates, nulls, negative sales, invalid dates and inconsistent category text so the cleaning step is realistic. The `Payment Mode` column is synthetic.

**Using the real Kaggle dataset instead:** search Kaggle for "Superstore Dataset" (file `Sample - Superstore.csv`), place it in `data/raw/`, then in the notebook change the `RAW` path. The real file has no `Payment Mode`, so add this after loading:
```python
import numpy as np
rng = np.random.default_rng(42)
df["Payment Mode"] = rng.choice(["Credit Card","Debit Card","UPI","Net Banking","Cash on Delivery","PayPal"], len(df),
                                p=[.30,.20,.18,.10,.12,.10])
```
Also note that product IDs in the real file can map to several product names, so check the `products` table logic. Numbers in `docs/` will differ and must be regenerated.

## How to run
1. **Python**
   ```bash
   pip install -r requirements.txt
   python scripts/generate_dataset.py      # only if you want to regenerate the raw data (run from project root)
   jupyter notebook notebooks/01_data_cleaning_and_eda.ipynb   # run all cells
   python scripts/run_tests.py             # 22 automated tests
   ```
2. **Oracle** (SQL Developer): run `sql/01_create_tables.sql`, load CSVs as described in `sql/02_load_data.md`, then run `03_analysis_queries.sql` and `04_validation_queries.sql`.
3. **Power BI:** follow `powerbi/03_dashboard_build_guide.md` (CSV or `vw_sales_flat` from Oracle).

## Database schema
```
customers (PK customer_id) 1 --- * orders (PK order_id, FK customer_id) 1 --- * order_items (PK row_id, FK order_id, FK product_id) * --- 1 products (PK product_id)
```
